# Guide de l'administration du site

Pour gérer les événements et les inscriptions de terra-indomita.ca.

## Se connecter

1. Ouvrir **https://terra-indomita.ca/admin/**.
2. Entrer son adresse courriel autorisée. Un code à six chiffres arrive par courriel.
3. Entrer le code. La session reste ouverte 24 heures.

Pour quitter : « Se déconnecter », en haut à droite.

Avant la mise en ligne, la version d'essai est à
**https://terra-indomita-staging.alexandre-lessard92.workers.dev/admin/**, avec la
même connexion. Rien de ce qui s'y fait n'apparaît sur le vrai site.

## Les événements

La page d'accueil de l'administration liste les événements **à venir** et **passés**.

- **Nouvel événement** : titre, début, fin (facultative), lieu, description, image.
  - Sans heure de fin, les inscriptions ferment à l'heure de début.
  - Les retours à la ligne de la description sont conservés sur le site.
  - Image : JPEG, PNG ou WebP, 8 Mo au maximum. Une image carrée ou horizontale
    s'affiche le mieux.
- **Modifier** : mêmes champs. « Retirer l'image » enlève l'image actuelle.
- **Supprimer l'événement** (au bas de la page Modifier) : demande une confirmation
  et efface aussi ses inscriptions.

Les changements paraissent sur le site en moins d'une minute.

### Afficher les événements en cours

- **Coché** : un événement commencé mais pas terminé apparaît « en cours » dans
  le calendrier.
- **Décoché** : il passe directement de « à venir » à « passé ».

## Les inscriptions

Chaque inscription envoie un courriel à Terra Indomita, avec le nom, le
courriel et le téléphone de la personne. **Répondre à ce courriel écrit
directement à la personne inscrite.**

Dans l'administration, le bouton **Inscriptions (n)** d'un événement donne :

- la liste des personnes inscrites ;
- **Télécharger en CSV (Excel)** pour la liste complète ;
- **Supprimer** une inscription, par exemple quand une personne demande le
  retrait de ses renseignements.

## Protection des renseignements personnels

La politique de confidentialité du site
(https://terra-indomita.ca/confidentialite/) prend deux engagements :

- les inscriptions sont effacées automatiquement **six mois après la fin de
  l'événement** — le site s'en charge ;
- les **courriels d'avis d'inscription** sont supprimés dans le même délai —
  cela, c'est à faire à la main dans la boîte courriel.

Une demande d'accès, de correction ou de suppression reçue à
info@terra-indomita.ca doit recevoir une réponse dans les 30 jours.
