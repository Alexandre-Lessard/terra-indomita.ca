# Branding and assets

## Colours

| Token | Value | Use |
|---|---|---|
| `brand-dark` | `#142012` | dark sections, admin header |
| `brand-dark-edge` | `#0d301a` | hero gradient |
| `brand-accent` | `#d4a455` | headings on dark, highlights |
| `brand-light` | `#fcf9f3` | text on dark, light backgrounds |

Defined in `frontend/src/app/globals.css`.

## Typography

Nunito (300, 400, 600, 700), loaded with `next/font/google`, which downloads the
files at build time and serves them from the site itself. Nunito is under the
SIL Open Font License 1.1.
